## 1近导航端物块

### 坐标

```bash
rostopic pub -1 /move_base_simple/goal geometry_msgs/PoseStamped "
  header:
    stamp: now
    frame_id: 'map'
  pose:
    position:
      x: -1.43569836894096
      y: -0.49503905352630406
      z: 0.0
    orientation:
      x: 0.0
      y: 0.0
      z: -0.02599500953578486
      w: 0.9996620726421677
  "
```

### 识别手臂位姿

```bash
rostopic pub /arm_controller/command trajectory_msgs/JointTrajectory "header:
  seq: 0
  stamp: {secs: 0, nsecs: 0}
  frame_id: ''
joint_names:
  ['arm_joint1','arm_joint2','arm_joint3','arm_joint4','arm_joint5']
points:
- positions: [0.0, 0.0, 0.9, 1.9, 0.0]
  time_from_start: {secs: 3, nsecs: 0}" -1
publishing and latching message for 3.0 seconds
```
