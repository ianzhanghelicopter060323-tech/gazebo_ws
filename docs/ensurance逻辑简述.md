# ensurance逻辑简述

## 1 整体逻辑

```txt
正常使用avoidance
|         |
|正常      |卡死
|         |
成功       启动ensurance----越过障碍恢复avoidance
          |
          |失败
          |
          （除准备位姿2）回退上一个导航点重新选点----继续导航
          |
          |失败
          |
          触发逃逸----成功后继续导航
          |
          |失败
          |
          报“卡死”错误
          
          
```

- 对于`ensurance`，其实就是`avoidance`但使用`base_line`的配置参数，保留“动态选点”逻辑，以实现无缝切换
