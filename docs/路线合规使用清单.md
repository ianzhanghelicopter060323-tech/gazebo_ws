# 路线相关使用清单（固定坐标 / 拟合路线 / 动态中间 goal / make_plan）

> 用途：提交给队友与竞赛合规核对的使用清单（阶段二）。**本清单只盘点、不调参、
> 不改代码**。所有改动均需等待合规结论；特别是固定仓库坐标、动态中间 goal、
> 拟合路线和调用 `/move_base/make_plan` 筛选路线，均存在明显规则风险。

> 规则依据（队友转述）：竞赛规则总手册要求官方全局规划器不得二次封装、不得拦截
> 输出，也不得硬编码赛道关键点（手册 603 行附近；评分条款见 578 行附近）。
> 基线：`TEB_test_bridge_fix`（由 `TEB_test@39d750c` 分出），盘点时点 2026-08-18。
